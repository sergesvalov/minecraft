# HalloumiTrader

[English](README.md) | **Русский**

Плагин для Paper 26.3: странствующий торговец, который продаёт халуми.

Клиентские моды не нужны. Работает и для Java, и для Bedrock-игроков (через Geyser).

## Как это выглядит в игре

- Время от времени рядом с кем-нибудь из игроков появляется **Торговец халуми** — странствующий торговец с золотым именем над головой.
- У него одна сделка: **4 халуми за 2 изумруда**, до 16 раз у одного торговца.
- Через 30 минут торговец уходит (исчезает), если с ним в этот момент никто не торгует.
- Когда торговец приходит, в чат пишется сообщение: «Торговец халуми пришёл к игроку …».

**Халуми** — это хлеб с названием «Халуми» и описанием «Жареный кипрский сыр». Он сытнее обычного хлеба: восстанавливает 8 единиц голода и 12.8 насыщения, как стейк. С обычным хлебом не складывается в одну стопку.

## Когда приходит торговец

Каждые 20 минут плагин бросает кубик:

1. Если в загруженных чанках уже есть торговец халуми, никто новый не приходит.
2. С шансом 50% торговец появляется рядом со случайным игроком.
3. Игрок должен быть в обычном мире (не в Незере и не в Энде) и не в режиме наблюдателя.
4. Место выбирается на поверхности в 10–20 блоках от игрока: твёрдый блок под ногами, без воды и лавы, два свободных блока по высоте. Если за 15 попыток подходящего места нет, визит пропускается до следующей проверки.

Всё это меняется в конфиге.

## Команды

Все команды доступны только опам (право `halloumi.admin`).

| Команда | Что делает |
|---|---|
| `/halloumi spawn` | Вызывает торговца в 2 блоках перед тобой. Для теста |
| `/halloumi random` | Сразу запускает случайный визит, без броска шанса и без лимита на количество |
| `/halloumi give [кол-во]` | Выдаёт халуми (по умолчанию 4, максимум 64) |
| `/halloumi count` | Показывает, сколько торговцев халуми сейчас в загруженных чанках |
| `/halloumi reload` | Перечитывает `config.yml` и перезапускает таймер визитов |

## Настройки

Файл на сервере: `/opt/minecraft/data/plugins/HalloumiTrader/config.yml`. Создаётся при первом запуске. После правки выполни `/halloumi reload`.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `trader-name` | `Торговец халуми` | Имя над головой торговца |
| `random-spawn.enabled` | `true` | Включить случайные визиты |
| `random-spawn.check-interval-minutes` | `20` | Как часто проверять, не пора ли прийти |
| `random-spawn.chance` | `0.5` | Шанс визита при каждой проверке (0–1) |
| `random-spawn.max-active` | `1` | Сколько торговцев может быть одновременно |
| `random-spawn.min-distance` / `max-distance` | `10` / `20` | Расстояние от игрока в блоках |
| `despawn-minutes` | `30` | Через сколько минут торговец уходит |
| `announce-message` | `Торговец халуми пришёл к игроку %player%! …` | Сообщение в чат; пустая строка — без сообщения |
| `trade.price-emeralds` | `2` | Цена в изумрудах |
| `trade.amount` | `4` | Сколько халуми за одну сделку |
| `trade.max-uses` | `16` | Сколько сделок у одного торговца |
| `halloumi.name` | `Халуми` | Название предмета |
| `halloumi.lore` | `Жареный кипрский сыр` | Строки описания |
| `halloumi.nutrition` / `saturation` | `8` / `12.8` | Сколько голода и насыщения восстанавливает |

Изменения цены и халуми применяются к новым торговцам. Тот, кто уже стоит в мире, сохраняет старую сделку.

## Сборка и деплой

Плагин собирается и выкатывается тем же пайплайном Jenkins, что и `WardenLog`:

```bash
bash scripts/build-plugin.sh HalloumiTrader
```

Скрипт собирает jar через Maven в Docker (`maven:3.9-eclipse-temurin-25`) и кладёт `HalloumiTrader-<версия>.jar` в `data/plugins/`. Если jar этой версии уже есть, сборка пропускается. **Чтобы выкатить изменения, подними `<version>` в `pom.xml`.**

При деплое Jenkins удаляет на сервере старые `HalloumiTrader-*.jar` и копирует новый.

## Как устроено

- Торговец — обычный ванильный `WanderingTrader`. От остальных его отличает метка в `PersistentDataContainer` (`halloumitrader:halloumi_trader`). Плагин отменяет `VillagerAcquireTradeEvent` для таких торговцев, чтобы ванильные сделки не добавлялись.
- Уход реализован через ванильный `despawnDelay`.
- Халуми — `BREAD` с компонентом `FOOD` (Paper Data Component API), названием, описанием и меткой `halloumitrader:halloumi`.
