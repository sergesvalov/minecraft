# 🧀 HalloumiTrader (`v1.6`) — Торговцы халуми и кипрские таверны

[← К общему описанию](../../README.md) · [Ресурспак «Халуми» →](../resourcepack.md)

Плагин для **Paper 26.3**: странствующие торговцы жареным сыром халуми и двухэтажные кипрские таверны, которые автоматически генерируются в новых чанках и заселяются трактирщиком и постояльцем. Работает для Java и Bedrock (иконки блюд подхватываются из [ресурспака](../resourcepack.md)).

---

## 1. Странствующий торговец халуми

- **Товар:** `4` куска **халуми** (8 голода и 12.8 насыщения, не стакается с обычным хлебом) за `2` изумруда, до `16` сделок; уходит через `30` минут (`despawn-minutes`).
- **Визиты:** каждые `20` минут в загруженных чанках проверяется лимит (`max-active: 1`, не считая гостей таверн) и шанс `50%`; торговец появляется в `10–20` блоках от случайного игрока в обычном мире (не в Spectator).
- **Подсказки:** при правом клике по торговцу он сообщает направление и округлённое расстояние до ближайшей таверны (кулдаун `60` сек на игрока).

---

## 2. Таверна «Халуми»

Генерируется `TavernPopulator` в новых чанках обычного мира по сетке `48 × 48` чанков (~770 блоков) с шансом `60%` на ячейку (с отступом от границ ячеек `8` чанков).

| Биом | Палитра (`TavernPalette`) |
|---|---|
| `plains`, `sunflower_plains`, `meadow`, `forest`, `flower_forest` | Дуб, булыжник, еловая крыша |
| `taiga`, `snowy_taiga`, `old_growth_*_taiga`, `snowy_plains`, `grove` | Ель, булыжник, крыша из тёмного дуба |
| `birch_forest`, `old_growth_birch_forest` | Берёза, булыжник |
| `savanna`, `savanna_plateau` | Акация, терракота |
| `desert` | Песчаник и детали из тропического дерева |
| `cherry_grove` | Вишня, каменный кирпич |
| `dark_forest`, `pale_garden` | Тёмный дуб, замшелый булыжник, крыша из глубинной плитки |
| `jungle`, `sparse_jungle`, `bamboo_jungle` | Тропическое дерево, замшелый булыжник |

### Устройство и NPC

- **Здание (`30 × 23` блока, двор до `z = 33`, высота `27`):** все двери и калитки двустворчатые; первый этаж — зал со стойкой трактирщика, кухней, столами и кафедрой с книгой «Меню»; второй этаж — коридор и `6` комнат для гостей; во дворе — мангал, коптильня и столики.
- **Сиденья (`Seats`):** на стульях лежат красные подушки (`BlockDisplay`); правый клик не на шифте сажает игрока или постояльца на невидимый маркер `ArmorStand`.
- **Трактирщик (`innkeeper`):** неуязвимый торговец без AI за стойкой (`despawnDelay = 0`), продаёт халуми и **14 кипрских блюд мезе** (`tavern.menu`: Сувлаки, Шефталья, Клефтико, Мусака, Кефтедес, Куппепья, Хориатики, Лукумадес, Пастицио, Рыбное мезе, Афелия, Флаунес, Суджукос, Кипрский кофе с эффектом скорости). Пополняет запасы при распродаже.
- **Постоялец (`resident`):** житель с выключенным vanilla AI, которого плагин каждый тик ведёт по маршрутам внутри таверны: днём покупает блюда и ест за столом, ночью поднимается в северо-западную комнату и спит до утра.
- **Гости (`tavern_guest`):** при присутствии игрока ближе `48` блоков в таверну заходят до `2` странствующих торговцев.
- **Миграция старых построек:** таверны версий до `1.4` (`OLD`, `OLD_EAST`, `OLD_WEST` в `taverns.txt`) сносятся автоматически при прогрузке чанков (`OldTaverns`).

## 3. Команды, права и конфигурация

| Команда | Права | Описание |
|---|---|---|
| `/halloumi tavern [стиль]` / `/halloumi inn [стиль]` | `halloumi.tavern` / `halloumi.inn` (`papa`) | Строит таверну прямо перед игроком; стили: `oak`, `spruce`, `birch`, `acacia`, `sandstone`, `cherry`, `dark_oak`, `jungle` |
| `/halloumi spawn` | `halloumi.admin` (op) | Вызывает торговца в 2 блоках перед игроком |
| `/halloumi random` | `halloumi.admin` (op) | Принудительно запускает случайный визит |
| `/halloumi give [кол-во]` | `halloumi.admin` (op) | Выдаёт 1–64 халуми (по умолчанию 4) |
| `/halloumi count` | `halloumi.admin` (op) | Число активных торговцев и известных таверн |
| `/halloumi taverns` | `halloumi.admin` (op) | Показывает 5 ближайших таверн |
| `/halloumi reload` | `halloumi.admin` (op) | Перезагружает [config.yml](../../plugins-src/HalloumiTrader/src/main/resources/config.yml), таймер, генератор и меню |

Новые блюда по умолчанию автоматически дописываются в существующий `config.yml` один раз при повышении `tavern.menu-version` (сейчас `2`). Список таверн хранится в `plugins/HalloumiTrader/taverns.txt`.

## 4. Архитектура, сборка и тесты

Пакеты в `com.server.halloumi`:
- `model`: `Dish`, `Tavern`, `TavernPalette`.
- `trade`: `MenuService` (халуми, рецепты, миграция меню, книга), `TraderService` (визиты, теги, кулдауны, подсказки).
- `tavern`: `TavernLayout`, `BlockGrid`, `BlockStates`, `TavernSite`, `TavernBuilder`, `TavernStorage`, `TavernPopulator`, `OldTaverns`, `TavernManager`.
- `npc`: `Seats`, `ResidentRoutes`, `Residents`.
- `command`: `HalloumiCommand`.

Сборка через Docker Maven:
```bash
bash scripts/build-plugin.sh HalloumiTrader
```
Модульные тесты JUnit 5: `HalloumiTest` и `TavernLogicTest`.
